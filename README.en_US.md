# AnvilCraft: NetEase Bedrock Edition

**NetEase Minecraft Bedrock Edition port of AnvilCraft, an anvil-centric vanilla survival expansion.**

[简体中文](README.md) | English

</div>

This repository ports the Java Edition mod [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) to NetEase Minecraft Bedrock Edition. Built around anvil impact processing, it expands vanilla survival with low-cost automation, power grids, fluid networks, and multi-step crafting.

The project is currently in early development. Feature migration planning and local development tooling are in place, and no playable package has been released yet.

## Planned Features

Gameplay systems are scheduled in phases around anvil mechanics and redstone automation:

- Anvil Processing: Block crushing, item crushing, item compression, block compression, stamping, mesh sieving, and stonecutter block breaking driven by falling anvils.
- Magnets and Logistics: Magnet blocks that lift and release anvils with redstone signals, paired with chutes, magnetic chutes, splitters, collectors, and crates for automated production lines.
- Power and Fluids: Power grids and fluid pipe networks supporting heaters, chargers, squeezing, bulging, crystallization, and super-heating recipes.
- Advanced Survival: Mineral fountains, crab traps, mob transformation, tools, equipment, amulets, ruby lasers, and an in-game recipe guide.
- Experimental Endgame Systems: Giant anvils, sliding rail contraptions, hyperdimension storage, and lunar celestial systems, each pending standalone engine verification on Bedrock Edition.
