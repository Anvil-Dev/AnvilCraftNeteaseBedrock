# 铁砧工艺：网易基岩版

**以铁砧为核心的原版生存拓展模组网易中国版（基岩版）移植项目。**

简体中文 | [English](README.en_US.md)

</div>

本仓库将 Java 版模组 [AnvilCraft（铁砧工艺）](https://github.com/Anvil-Dev/AnvilCraft) 移植到《我的世界》中国版基岩端。项目围绕铁砧的下落冲击与加工展开，在保留原版生存节奏的基础上加入低成本自动化、电网、流体与多步加工玩法。

当前开发代码支持 340 条原版落砧配方，包含 12 条方块粉碎、33 条物品压缩、54 条解包、9 条双方块压合、4 条炼药锅方块压榨、12 条脚手架筛分、122 条方块涂抹、89 条物品粉碎和 5 条冲压。双方块压合与涂抹优先于粉碎。首次进入世界会获得《铁砧工艺手册》，可在游戏内查看原料、用量和概率。[已移植配方](docs/recipes.md)

四种专用加工台可投料、改装和回收库存，磁铁块与空心磁铁块通过红石控制铁砧循环，溜槽和磁力溜槽负责收集、入箱与加工台投料。新增功能已通过 Python 2.7 自动化回放，游戏内表现待验收。[磁铁与物流用法](docs/mechanisms.md)

使用网易 3.10 工作台开发测试时，在仓库根目录运行 `python -B tools/package_addon.py`，再通过「本地导入」选择 `dist/AnvilCraft-Studio.zip`。[导入说明](docs/development.md#在-mc-studio-导入附加包)

## 规划玩法

模组围绕铁砧与红石机械扩展生存体验，按以下阶段推进实现：

- 铁砧加工：利用铁砧下落完成方块粉碎、物品粉碎、物品压缩、方块压合、冲压、筛分与切石机破拆。
- 磁铁与物流：使用磁铁吸起铁砧并通过红石信号控制释放，配合溜槽、磁力溜槽、分流器、收集器与木箱组建自动产线。
- 电力与流体：搭建电网与储液管网，使用加热器、充放电机、压榨、膨发、晶化与高温加工处理大宗资源。
- 进阶生存：加入矿物涌泉、捕蟹笼、生物转化、工具装备、护符、红宝石激光与游戏内配方手册。
- 远期实验内容：巨型铁砧、滑动导轨移动结构、超维存储与月球天体系统需在基岩版引擎中单独验证后决定发布范围。
